## ✨ About

Spooz Linux OS is a custom Linux distribution made for users who want a modern desktop experience with great performance and customization.

Whether you are a gamer, developer or Linux enthusiast, Spooz Linux OS aims to provide a clean and powerful environment.

---

## 🔥 Features

- Modern desktop interface
- Lightweight and fast
- GNOME support
- Gaming ready
- Custom themes
- Linux customization tools
- Open-source software
